# 🐺 Goat AFK Rewards — Official Minecraft AFK & Discord Bot Platform

نظام ذكي متكامل لإدارة جلسات الفرم والخمول (AFK Farming) لماينكرافت، متصل ببوت ديسكورد تفاعلي، ومزوّد بموقع ويب رسمي يعمل مباشرةً من خادم البوت نفسه مع بوابة دفع سوبر كي (SuperQi) ونظام تحقق وموافقة بنقرة واحدة مع لقطات الشاشة!

---

## 🌟 الميزات الرئيسية (Key Features)

### 1. موقع ويب متكامل يعمل مباشرة من البوت (Built-in Web Server)
- يعمل خادم الويب مباشرةً داخل البوت على المنفذ `3001` (أو المنفذ المحدد عبر `PORT`).
- بمجرد تشغيل البوت وفتح رابط السيرفر في المتصفح (`http://localhost:3001` أو رابط خادم الـ VPS الخارجي)، يفتح الموقع الرسمي بكامل ملفاته وتصاميمه.
- واجهة مستخدم سايبربانك تفاعلية بمؤثرات صوتية، شريط تنقل سلس، وعرض مباشر لخطط الاشتراك.

### 2. الشعار الذهبي الملكي للديسكورد (24k Gold Emblem)
- تم تزويد البوت بنسخة ذهبية ملكية فاخرة للشعار (`goat_avatar_gold.png`).
- تظهر النسخة الذهبية الفاخرة حصرياً داخل الديسكورد (صورة بروفايل البوت + Embeds الإشعارات والمكافآت).

### 3. بوابة دفع سوبر كي والتحقق بنقرة واحدة (SuperQi 1-Click Verification)
- مسح باركود سوبر كي (SuperQi) باسم **(وليد عباس)** لدفع رسوم الاشتراك.
- **إرفاق لقطة شاشة لإشعار التحويل (وصل الدفع):** يمكن للزبون رفع سكرين شوت أو سحبها وإفلاتها أو لصقها عبر `Ctrl + V`.
- **أمان 100%:** لا يُسلّم أي كود تلقائياً قبل التحقق!
- **إشعار تفاعلي خاص للمالك:** تصل رسالة DM تفاعلية لمالك البوت تتضمن صورة الوصل كاملة وزرّين:
  - 🟢 `[ ✅ قبول وتوليد الكود ]` -> يولد كود الترخيص ويرسله تلقائياً لخاص المشتري مع أمر السلاش الجاهز.
  - 🔴 `[ ❌ رفض الطلب ]` -> يُلغي المعاملة ويُشعر المشتري بلباقة.

### 4. أوامر ديسكورد التفاعلية (Discord Commands)
- `/redeem code:<كودك>` — تفعيل كود الاشتراك المشترى.
- `/farm_start server:<server> username:<player>` — بدء جلسة الفرم لحساب المشترك.
- `/farm_stop` — إيقاف جلسة البوت وحفظ الموارد.
- `/my_bot` — عرض حالة الاشتراك والوقت المتبقي.
- `/plans` — استعراض باقات الفرم وأسعارها بالدولار والدينار العراقي.
- `/status` — تقرير مباشر عن حالة السيرفر والخمول.
- `/create_code plan:<باقة>` — (للمالك فقط) توليد كود ترخيص يدوي.

## 🚀 طريقة التشغيل (Quick Start)

### 1. تثبيت الحزم (Installation)
```bash
npm install
```

### 2. تشغيل الموقع وبوت الديسكورد معاً
```bash
# عبر node مباشرة:
node discord_bot.js

# أو عبر ملف التشغيل السريع في ويندوز:
run_discord_bot.bat
```

### 3. فتح الموقع في المتصفح
بعد التشغيل، افتح الرابط التالي في أي متصفح:
```
http://localhost:3001
```
*(أو استبدل `localhost` بآيدي سيرفرك أو عنوان الـ VPS)*

## 📦 رفع المشروع إلى GitHub (Push to GitHub)

لرفع المشروع إلى مستودعك على GitHub، اتبع الخطوات التالية:

```bash
# 1. تهيئة المستودع
git init

# 2. إضافة كافة الملفات
git add .

# 3. حفظ التغييرات الأولى
git commit -m "feat: Goat AFK Rewards Bot & Web Platform with SuperQi Approval System"

# 4. تغيير اسم الفرع إلى main
git branch -M main

# 5. ربط المستودع برابط مستودعك على GitHub
git remote add origin https://github.com/iraq2296/-Goat-AFK-Rewards.git

# 6. الرفع إلى GitHub
git push -u origin main
```

## ⚙️ ملفات التكوين (Configuration)

- `config.json` — ضبط توكن الديسكورد والبادئة وخيارات ماينكرافت.
- `subscriptions_db.json` — قاعدة بيانات التراخيص والطلبات المعلقة والاشتراكات النشطة.
- `.env.example` — نموذج لمتغيرات البيئة للتشغيل على السيرفرات السحابية.
